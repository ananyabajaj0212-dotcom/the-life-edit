# THE LIFE EDIT — installable PWA package

A responsive, single-file personal dashboard with a Muted Romance theme. No build step is required.

## Publish it (free hosting)
1. Create a GitHub account if you do not already have one.
2. Create a new **public** repository named `the-life-edit`.
3. Upload the contents of this folder (not the folder itself) to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your HTTPS app address will be shown in the Pages settings.

## Install on iPhone
1. Open the published HTTPS address in **Safari**.
2. Tap Share → **Add to Home Screen**.
3. Keep “Open as Web App” enabled if shown, then tap Add.

## Add to Brave on Mac
1. Open the same HTTPS address in Brave.
2. Use the address-bar install icon if shown, or open **⋮ → Save and share → Install page as app** (wording may vary).
3. Pin the installed app or add the page as a Brave shortcut/bookmark.

## Important data note
This build stores entries locally in each browser/device. It does **not** provide account login or cloud sync, so iPhone and Mac data will not automatically merge. Use Settings → Export/Import to keep backups and move a backup manually between devices. Do not store highly sensitive information in this prototype.

The app shell and icon assets are configured for offline/PWA use after the first successful HTTPS load. Some browser features and external fonts may still need an internet connection.
